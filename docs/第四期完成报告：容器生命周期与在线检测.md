## 架构说明

```
心跳流程:
前端 (30s)  →  POST /heartbeat  →  更新 last_heartbeat_at
后端 (60s)  →  扫描 find_stale_containers(120s)  →  stop_container

退出流程（双保险）:
方案1: sendBeacon /stop-on-exit (Token in body) → 立即停止
方案2: 120s 心跳超时 → 后端定时任务自动停止
```
