# 教师端管理模块：待实现功能详细清单

本清单仅列出代码库中尚未实现但 `SDD-第五期：教师端管理模块.md` 中明确要求的核心功能、接口及逻辑。

## 1. 前端模块 (edubot-twin-web)

### 1.1 学生管理 (`src/views/Teacher/Students/`)
- **[ ] 搜索功能**: `Student.vue` 缺少顶部的搜索表单（Search Form），无法按用户名或姓名过滤学生列表。
- **[ ] 批量删除**: 虽然 UI 上有按钮，但 `Student.vue` 中仅实现了单个删除，尚未实现表格的多选批量删除逻辑。

### 1.2 容器监控 (`src/views/Teacher/Containers/`)
- **[ ] 实时数据展示**: `Monitor.vue` 的表格中缺失以下实时监控列：
  - **CPU 占用率** (`cpu_percent`): 动态展示容器当前的 CPU 百分比。
  - **内存占用** (`memory_mb`): 展示容器当前消耗的内存（MB）。
  - **运行时长** (`uptime_seconds`): 展示容器从启动至今的连续运行秒数。
- **[ ] 状态展示增强**:
  - `status` 字段的 Slot 逻辑中缺少对 `removing`（删除中）状态的处理和 `el-tag` 颜色映射。
  - 缺少 `el-progress` 进度条组件来呈现资源占用。

### 1.3 类型与 API 定义
- **[ ] 类型定义位置**: SDD 建议在 `src/api/teacher/types.ts` 中统一定义，当前分散在 `student` 等目录下。
- **[ ] 监控数据模型**: 缺少 `ContainerMonitorInfo` 接口定义，导致前端目前直接引用不完整的 `ContainerResponse`。

---

## 2. 后端模块 (edubot-twin-server)

### 2.1 容器监控接口 (`app/api/v1/endpoints/teacher/`)
- **[ ] 专用监控 endpoint**: 缺少专门的 `/api/v1/teachers/containers/monitor` 接口（目前前端调用的是根路径列表）。
- **[ ] `monitor.py`**: SDD 8.1.1 建议创建独立的监控视图文件，目前逻辑混杂在 `containers.py` 中。

### 2.2 核心业务逻辑 (Core Logic)
- **[ ] Docker 实时统计获取**: `app/core/container_manager.py` 尚未封装获取容器 `stats` 的异步方法。
- **[ ] CPU 计算算法**: 缺少根据 Docker 原生 `cpu_delta` 和 `system_cpu_delta` 计算 `cpu_percent` 的具体实现代码（SDD 6.1 伪代码逻辑）。

### 2.3 数据 Schema (app/schemas/container.py)
- **[ ] 监控响应模型**: `ContainerResponse` 缺失以下动态字段：
  - `student_name` / `student_username`: 用于列表展示，无需前端二次关联。
  - `cpu_percent`, `memory_mb`, `memory_limit_mb`, `uptime_seconds`: 实时性能数据。
  - `purpose`: 容器用途。

---

## 3. 命名与规范偏差
- **接口路径**: 后端容器管理路径当前为 `/api/v1/teachers/containers`，而 SDD 要求的监控路径为 `/api/v1/teachers/containers/monitor`。
