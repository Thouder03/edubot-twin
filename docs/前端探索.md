指令 (Vue → iframe):

- gz:showOrbitIndicator - 显示轨道指示器

事件 (iframe → Vue):
- gz:ready - iframe 就绪
- gz:connection - 连接状态
- gz:paused - 暂停状态
- gz:simTime - 仿真时间
- gz:realTime - 实时时间
- gz:pong - 心跳应答

状态管理:
- connectionStatus: 'disconnected' | 'connecting' | 'connected' | 'error'
- isPaused: boolean
- simTime: string (HH:MM:SS.mmm)
- realTime: string
- isBridgeReady: boolean
- isAttached: boolean (iframe 是否挂载到 GzWebViewer)

总结: 核心架构层次
================================================================================

Front-End Page (Single-Tab Simulation)
├─ Simulation.vue (主容器)
│  ├─ useGzBridge (页面级 iframe 初始化)
│  ├─ usePanelState (全局面板状态)
│  └─ GLayout (Golden Layout 集成)
│     ├─ Virtual Components Rendering (Teleport)
│     └─ Panel Registry (自动加载)
├─ SimulationHeader (工具栏)
│ ├─ SimControlBar (GzBridge 指令)
│ ├─ Layout Presets Menu
│ └─ Add Panel Menu
└─ SettingsSidebar (设置面板)
   └─ Dynamic Settings Tree Rendering

Panel Examples:
- GzWebViewer: attachToContainer + config + settings
- WorkspacePanel: FileTree + EditorWorkbench + useWorkspace
- KeyboardControl, ContainerTerminal, RosoutPanel, CameraPanel

Student Flow:
1. Student/Home.vue - 选择实验版本
2. 启动仿真 (POST /api/v1/students/simulation/start)
3. 轮询等待任务完成 (GET /api/v1/students/tasks/{taskId})
4. 打开 Simulation.vue (新标签页)
5. 初始化 GzBridge + 获取容器 URL
6. 启动心跳 + 监听容器状态

Teacher Flow:
1. Teacher/Experiments/Experiments.vue - 实验列表
2. 点击"详情管理" → ExperimentDetail.vue
3. 创建版本 (POST /api/v1/teachers/experiments/{id}/versions)
4. 编辑版本参数 (PUT /api/v1/teachers/experiments/{id}/versions/{id})
5. 发布版本 (POST /api/v1/teachers/experiments/{id}/versions/{id}/publish)
