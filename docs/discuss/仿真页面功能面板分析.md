## 二、毕设需求对照分析

### 核心需求回顾

根据你的毕设任务书，核心要求是：

1. **数字孪生可视化**：实时渲染栅格地图、TF坐标变换、激光雷达点云、规划路径
2. **实训任务管理**：支持"实训模式"与"考核模式"
3. **代码/工程下发**：学生在线获取模板工程，下发控制指令或导航目标点
4. **简单评测**：定性评测（如机器人是否到达目标点）
5. **实时观察反馈**：学生能实时观察机器人在数字孪生环境中的反馈

### 3.3 可选功能（P2）

#### ⚠️ 摄像头监控面板

**评估**: 
- ✅ 优点: 增强沉浸感，学生能看到"机器人视角"
- ❌ 缺点: 需要额外的视频流传输（WebRTC/MJPEG）

**建议**: 
- **毕设阶段**: 可以暂时不实现
- **如果要做**: 使用 `web_video_server` ROS包，订阅 `/camera/image_raw`

**优先级**: 如果核心功能都完成了，可以作为"加分项"

---

### 3.4 不建议实现的功能（P3）

#### ❌ 容器内命令行面板（面板9）

**问题**:
1. **安全风险极高**: 即使限制路径，学生仍可能执行危险命令（`rm -rf`, `kill`）
2. **不符合教学场景**: 实训应该是"结构化任务"，而非自由探索
3. **评测困难**: 无法标准化评价学生在终端的操作

**建议**: **完全移除此功能**

**替代方案**: 
- 如果学生需要调试，提供"预定义命令"按钮
- 例如: [查看话题列表] [查看节点列表] [检查TF树]
- 后端白名单执行: `rostopic list`, `rosnode list`, `rosrun tf view_frames`

## 五、具体实现建议

### 5.1 键盘控制面板

**技术方案**:
```typescript
// 前端: 监听键盘事件
document.addEventListener('keydown', (e) => {
  if (e.key === 'ArrowUp') {
    publishCmdVel({ linear: 0.5, angular: 0 })
  }
})

// 后端: 转发到ROS
async def publish_cmd_vel(container_id: int, linear: float, angular: float):
    # 使用 roslibpy 发布到容器内的 /cmd_vel Topic
    client = roslibpy.Ros(host=container_host, port=rosbridge_port)
    topic = roslibpy.Topic(client, '/cmd_vel', 'geometry_msgs/Twist')
    topic.publish({
        'linear': {'x': linear, 'y': 0, 'z': 0},
        'angular': {'x': 0, 'y': 0, 'z': angular}
    })
```

**UI设计**: 参考 ROS Web Tools 的 `keyboardteleop` 组件

---

### 5.2 工程管理面板

**文件上传流程**:
```
学生上传 .zip → 后端解压到容器 /home/student/workspace/
                → 返回文件列表
                → 前端显示文件树
```

**执行流程**:
```
学生点击"执行 nav.launch" 
  → POST /api/v1/student/nodes/start
  → 后端: docker exec <container> roslaunch nav.launch
  → 返回节点ID
  → 前端轮询节点状态
```

**API设计**:
```python
# 启动节点
POST /api/v1/student/nodes/start
{
  "launch_file": "navigation.launch",
  "params": {"map_file": "map.yaml"}
}

# 停止节点
POST /api/v1/student/nodes/{node_id}/stop

# 查询运行中的节点
GET /api/v1/student/nodes
```

### 5.3 ROS日志面板

**技术方案**:
```typescript
// 前端: WebSocket 订阅 /rosout
const ros = new ROSLIB.Ros({ url: rosbridgeUrl })
const rosTopic = new ROSLIB.Topic({
  ros: ros,
  name: '/rosout',
  messageType: 'rosgraph_msgs/Log'
})

rosTopic.subscribe((message) => {
  logStore.addLog({
    level: message.level,  // 1=DEBUG, 2=INFO, 4=WARN, 8=ERROR
    name: message.name,    // 节点名
    msg: message.msg       // 日志内容
  })
})
```

**UI设计**:
- 自动滚动到最新日志
- 颜色区分: INFO(蓝) WARN(黄) ERROR(红)
- 过滤器: 按级别、按节点名

## 七、总结
